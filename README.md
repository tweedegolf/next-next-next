# next next next

Welcome to these community Rustlings exercises 😃 A collection of excercises to learn about iterators.

## Getting started

* First, [install Rustlings using the official instructions](https://github.com/rust-lang/rustlings) ✅

* Then, clone this repository.

* Then download the May 2026 dataset from <https://www.rijdendetreinen.nl/en/open-data/train-archive#downloads> and place it in this directory next to `README.md`, `Cargo.toml`, etc.

* Lastly, open a terminal in this directory and run `rustlings` to get started with the exercises 🚀.

* If you are unfamiliar with Rustlings check out their [usage guide](https://rustlings.rust-lang.org/usage/) for more information.

## Student guide

next next next will be used as part of a mentoring program to learn Rust, offered by
Tweede Golf and the Dutch Electoral Council. A student guide to the program is being
