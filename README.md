Welcome to these community Rustlings exercises 😃 A collection of excercises to learn about iterators.

First, [install Rustlings using the official instructions](https://github.com/rust-lang/rustlings) ✅

Then, clone this repository.

You need to download the May 2026 dataset from https://www.rijdendetreinen.nl/en/open-data/train-archive#downloads and place it in this directory next to `README.md`, `Cargo.toml`, etc.

Lastly, open a terminal in this directory and run `rustlings` to get started with the exercises 🚀
